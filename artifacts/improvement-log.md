# 개선 기록

## 2026-08-30 · 1차 전문가 검토 반영

- CSS 도형 영웅 캐릭터를 색연필·구아슈·종이 콜라주 키 비주얼로 교체
- 네 모험 세계를 하나의 일관된 그림책 지도 자산으로 추가
- 1024px 이하 한 열 전환과 모바일 진행 표시로 태블릿 가로 넘침 제거
- 보호자 사진 동의를 실제 체크박스로 전환하고 안내 문구를 처리 범위에 맞게 수정
- 카메라 촬영 입력 분리, 업로드 메시지의 과장된 품질 판정 제거
- 부분 이미지 생성 성공 시 첫 유효 후보를 자동 선택
- 연령대를 대화 API에 연결하고 가짜 음성 버튼 제거
- 모험 선택을 기록해 캐릭터 페르소나·테마와 함께 7페이지 동화책에 반영
- 대화 로그·오류·동화책 내비게이션 접근성 보완

## 2026-08-30 · 2차 하네스 검토 반영

- 입력 역할 allowlist, 페르소나 길이 제한, 제어문자 제거
- 전화번호·이메일 형식과 띄어쓴 위험 발화 검출 강화
- 모델 출력의 관계 안전 재검사와 25초 응답 제한 추가
- 이미지 magic byte 검사와 15분당 생성 제한 추가
- 정상/경계/결함 주입 안전 회귀 세트 추가

## 2026-08-30 · 3차 PM 검토 반영

- 보호자 동의를 기본 미선택으로 바꾸고 보호자 공간 진입을 동의 완료 뒤로 제한
- 표시뿐이던 시간 선택을 제거하고 “5개 장면 · 보통 8–12분”으로 약속을 정직하게 조정
- 새 그림과 전체 삭제 시 페르소나·대화·모험·책·동의까지 한 번에 초기화하고 진행 중 요청 취소
- 보호자 화면을 열기 전 아이 화면을 기억해 정확한 단계로 복귀
- 모험 완료 시 책의 본문·캐릭터 이미지·테마를 스냅샷으로 고정
- 직전 선택이 다음 장면에 반응 문장으로 나타나고, 모든 선택이 책에 기록되도록 연결
- “진짜 친구”, “영구 보관”처럼 실제 범위를 넘는 문구를 AI·현재 세션 중심 표현으로 수정

## 재검토 조건

- 실제 계정·영구 저장·음성 기능을 추가할 때 보호자 인증과 삭제 API를 다시 설계한다.
- 실제 아동 베타 전 아동 안전 전문가와 법률 검토를 별도로 통과해야 한다.
- 캐릭터 보존 점수를 자동 평가하는 골든 이미지 세트를 확보하면 생성 후 비전 품질 게이트를 추가한다.
