# 그림친구 3차 품질 검토 계약

## Phase 0–2 · 상황과 산출물

- 목표: 6–9세 아이가 자기 그림을 알아보고, 안전하게 대화·모험한 뒤 자기 선택이 담긴 책을 끝까지 보는 서비스
- 기준 자료: PRD v0.1, 운영 화면, 캐릭터·채팅 API, 데스크톱/태블릿/모바일 흐름
- 최종 산출물: 검증된 운영 사이트, 재실행 가능한 안전 검사, 개선 기록

## Phase 3–6 · 역할과 흐름

1. 시니어 디자이너가 그래픽 서사·타이포·색·반응형·접근성을 평가한다.
2. 시니어 개발자가 상태 연결·오류·모바일·키보드·빌드 가능성을 평가한다.
3. 시니어 AI 엔지니어가 변환 품질·프롬프트 경계·아동 안전·비용 위험을 평가한다.
4. 생성자와 평가자를 분리해 수정 뒤 외부 신호(타입 검사, 빌드, API 회귀, 브라우저 화면)로 합격 여부를 판단한다.
5. PM이 PRD의 핵심 루프와 의미 있는 창작 완성률 관점에서 범위를 다시 줄이고 연결한다.

## Phase 7 · 검증과 종료 계약

- 결정적 검사: `npx tsc --noEmit`, `npm run build`, `npm run test:safety`
- 시각 검사: 가로 넘침 없음, 키 비주얼이 첫 여정에서 보임, 모바일 진행·캐릭터 관계 유지
- 제품 검사: 테마·이름·능력·각 장면 선택이 동화책에 반영됨
- 안전 검사: 전화번호/이메일 우회, 띄어쓴 위기 발화, 역할 위조, 빈 입력을 포함
- 반복 상한: 세 차례. 이전보다 품질이 떨어지면 가장 좋은 버전으로 되돌린다.
- 배포는 모든 결정적 검사가 통과한 뒤에만 진행한다.
